PORTAL KINERJA AHASS — CORPORATE LIGHT

Isi paket:
- index.html
- style.css
- script.js

Pembaruan style:
- Latar putih dan abu-abu sangat terang
- Aksen navy blue, biru korporat, dan detail emas yang halus
- Tipografi profesional, kartu dashboard rapi, responsif untuk desktop dan mobile
- Tiga dashboard tetap independen dan dibuka di tab baru

Tautan dashboard:
1. Performa Digital
   https://tsd-asmosumsel.github.io/Performance-Digital-ASMOSumsel/
2. Pencapaian LCR
   https://tsd-asmosumsel.github.io/LCR-Achievement-Dashboard/
3. Performa AMORE
   https://tsd-asmosumsel.github.io/amore-dashboard-sumsel/

Cara memasang:
1. Ekstrak ZIP ini.
2. Buka repository ahass-performance-portal di GitHub.
3. Ganti index.html, style.css, dan script.js di root repository dengan file dari paket ini.
4. Commit perubahan.
5. Buka kembali GitHub Pages portal untuk melihat desain baru.

Tidak perlu mengubah kode atau koneksi data di masing-masing dashboard.
